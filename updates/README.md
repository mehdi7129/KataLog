# Mises à jour de KataLog

Le flux stable signé est servi sous `stable/appcast.xml`. La clé publique
Ed25519 correspondante se trouve dans `stable/public-key.txt`. Aucune clé
privée n’est stockée dans le dépôt.

URL du flux : https://raw.githubusercontent.com/mehdi7129/KataLog/main/updates/stable/appcast.xml

Voir [la procédure de release](../docs/RELEASING.md). Publier les archives
finales avant le nouveau flux. Un feed signé ne doit pas être reformaté après signature.
